# Crypto All-in-One Chart & Indicators

Bộ indicator phân tích kỹ thuật crypto (combine từ nhiều nguồn) gồm **2 phần**:

## 1) Pine Script (chạy trên TradingView.com)
| File | Nội dung |
|---|---|
| `AllInOne_VWMA_Wyckoff_Liquidity_FearGreed.pine` | VWMA + FearZone + GreedZone + Liquidity Spectrum + Wyckoff Acc/Dist |
| `AllInOne_Zeiierman_LuxAlgo_VSA.pine` | FearZone + GreedZone + S/R Breaks + VSA Wyckoff Volume |
| `3in1_VWMA_Liquidity_Wyckoff.pine` | VWMA + Liquidity Spectrum + Wyckoff Acc/Dist |

→ Mở [Pine Editor](https://www.tradingview.com) → dán code → **Add to chart**.

## 2) Web App (chạy trên trình duyệt / GitHub Pages)
Thư mục [`docs/`](docs/) — tái hiện các indicator bằng JavaScript trên
[lightweight-charts](https://github.com/tradingview/lightweight-charts), dữ liệu từ Binance API.

🔗 **Live demo (sau khi bật Pages):** `https://kevink6truong-glitch.github.io/crypto-allinone-chart/`

Xem chi tiết & giới hạn tại [docs/README.md](docs/README.md).
